bash — fresh install on Ubuntu LTS
# 1. Clone the repository
git clone https://github.com/mahirgul/AiPBX.git /opt/aipbx
cd /opt/aipbx

# 2. Run automated fresh installer (auto-generates all passwords & TLS)
sudo bash install.sh

Engineered for Reliability & Control

Everything your enterprise needs for secure voice, messaging, and administration.

📞

Dual-Endpoint PBX

Seamless PJSIP architecture where every extension works simultaneously on standard SIP desk phones and WebRTC softphones.

🌐

WebRTC Softphone

In-browser zero-install SIP phone powered by Opus HD audio and integrated coturn TURN/STUN NAT traversal.

📱

Native Android App

Full-featured Kotlin mobile application with FCM background wake-up, built-in real-time chat, and diagnostics log viewer.

💬

Real-Time Chat Engine

Lightning-fast instant messaging service built in Go with WebSocket event streaming, typing indicators, and read receipts.

📠

Digital Fax Center

Inbound and outbound T.38 / G.711 fax server with browser WYSIWYG editor, PDF upload, auto-retry, and email forwarding.

🔒

Enterprise Security

Least-privilege MariaDB separation (DML vs DDL), fail2ban protection, CSRF validation, and brute-force lockout.

Modern Technology Stack

Built with battle-tested open-source components.

Asterisk 22 LTS PHP 8.x (Strict MVC) MariaDB 11 Go (Gorilla WS) Android (Kotlin) coturn (TURN/STUN) Apache 2.4 (WSS Proxy) fail2ban
