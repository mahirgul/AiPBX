bash — Quick One-Line Install (Ubuntu 22.04 / 24.04 / 26.04 LTS)
# Tek satırda tam otomatik santral kurulumu (One-liner turnkey install)
curl -fsSL https://raw.githubusercontent.com/mahirgul/AiPBX/main/install.sh | sudo bash

# Veya kaynak koddan kurulum (Alternative git clone)
git clone https://github.com/mahirgul/AiPBX.git /opt/aipbx && cd /opt/aipbx && sudo bash install.sh

AI PBX

Açık kaynak, yüksek eşzamanlılıklı kurumsal IP PBX ve Birleşik İletişim Platformu. Kısıtlayıcı güvenlik duvarlarını aşan Port 443 ALPN mimarisi, Asterisk 22, WebRTC, Go WebSocket sohbet motoru ve yerel mobil istemciler.

Open-source, high-concurrency enterprise IP PBX and Unified Communications platform. Featuring Port 443 ALPN multiplexing for restrictive firewalls, Asterisk 22, WebRTC, Go WebSocket chat, and native mobile apps.

Open-Source Enterprise IP-Telefonanlage und Unified Communications Plattform mit hoher Nebenstellen-Kapazität. Port 443 ALPN-Multiplexing für restriktive Firewalls, Asterisk 22, WebRTC, Go-Chat und native Mobil-Apps.
