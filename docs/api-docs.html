🔌 REST API & Geliştirici Kılavuzu

AiPBX; CRM sistemleri, ERP yazılımları, mobil istemciler ve harici çağrı merkezi panelleri ile çift yönlü entegrasyon kurabilen modern REST API ve WebSocket arayüzleri sunar.

1. Kod Tabanı & Mimari Standartları

AiPBX web katmanı, harici ağır framework'lere bağımlı olmaksızın hafif, saf bir PHP 8 MVC (Model-View-Controller) mimarisi uygular:

  • Beyaz Liste Yönlendirici (Whitelist Router): index.php dosyasındaki $ROUTES dizisinde tanımlanmamış hiçbir URL çalıştırılamaz (Doğrudan 404 üretilir).
  • Ayrılmış Katmanlar:
    • src/controllers/: Yalnızca yetki denetimi, HTTP girdi doğrulama ve yanıt orkestrasyonu yapar.
    • src/services/: İş kurallarını (business logic) işletir, veritabanına yazar ve Asterisk senkronizasyonunu tetikler.
    • src/repositories/: Salt-okunur (read-only) SQL sorgularını çalıştırır.
    • src/sync/: Veritabanındaki değişiklikleri Asterisk .conf dosyalarına dönüştürür ve geri alma (rollback) güvencesiyle Asterisk'i yeniden yükler.

2. REST API Uç Noktaları (Endpoints)

Tüm API istekleri standart JSON formatında yanıt döner ve oturum çerezi (Session Cookie) veya API Token ile kimlik doğrulaması yapar:

Metot Uç Nokta (Endpoint) Açıklama Yetki
POST /api/auth/login Dahili veya kullanıcı adı ve şifre ile oturum açar, yetki rolünü döner. Herkes
GET /api/mobile/contacts.php Santraldeki tüm kurumsal dahilileri, isimleri ve anlık varlık durumlarını listeler. Kullanıcı
GET /api/mobile/history.php Kullanıcının gelen, giden ve cevapsız çağrı geçmişini (CDR) döner. Kullanıcı
POST /api/mobile/features.php DND (Rahatsız Etmeyin) ve Çağrı Yönlendirme durumunu günceller. Kullanıcı
POST /api/cc_actions/agent.php Temsilcinin mola durumunu (*22/*23) ve kuyruk giriş/çıkışını yönetir. Temsilci / Admin
GET /api/cc_actions/queues.php Çağrı merkezi kuyruklarının anlık metriklerini (bekleyen, konuşan, mola) döner. Yönetici

Örnek Yanıt Formatı:

3. Go Real-Time WebSocket Sohbet Protokolü

AiPBX anlık mesajlaşma istemcileri (Android, iOS ve Web) wss://santral.sirket.com/chat/ws adresine bağlanır. Tüm veri transferi hafif JSON paketleriyle yürütülür:

Paket Tipi (Type) Yön Kullanım Amacı
auth İstemci -> Sunucu İlk bağlantıda dahili kimliğini ve oturum anahtarını iletir.
message Çift Yönlü Bireysel veya grup sohbet metin mesajı iletimi.
typing Çift Yönlü "Karşı taraf yazıyor..." anlık durum bildirimi.
presence Sunucu -> İstemci Dahilinin çevrimiçi, çevrimdışı veya molada olduğunu yayınlar.

Örnek Mesaj Paketi:

JSON Sohbet Paketi 
{
  "type": "message",
  "from": "1000",
  "to": "2001",
  "group_id": null,
  "content": "Toplantı 14:00'te başlayacaktır.",
  "timestamp": 1773738000,
  "message_id": "msg_98f12a4b"
}

4. Otomatik Test Paketi (PHPUnit CI/CD)

AiPBX kod tabanında 140'tan fazla birim ve entegrasyon testi bulunmaktadır. Her yeni kod değişikliğinde testlerin çalıştırılması zorunludur:

Terminal Test Komutu 
# 1. Test veritabanını hazırlayın
bash bin/setup-test-db.sh

# 2. PHPUnit testlerini çalıştırın
./vendor/bin/phpunit

# Beklenen Çıktı:
# OK (142 tests, 350 assertions)
