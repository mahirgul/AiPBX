🚀 Kurulum & Sistem Yönetim Kılavuzu

AiPBX; Asterisk 22, MariaDB 11, Nginx L4, Apache 2.4, Go Chat motoru ve Coturn TURNS servisini tek bir otomatik betikle (install.sh) 5 dakikada kurup çalışır hale getirir.

1. Sistem Gereksinimleri & Donanım Boyutlandırma

AiPBX, temiz ve güncel bir Linux sunucu üzerine kurulmalıdır:

Parametre Minimum Gereksinim (Geliştirme / Test) Önerilen Prodüksiyon (50-200 Dahili)
İşletim Sistemi Ubuntu Server 22.04 / 24.04 LTS (x86_64) Ubuntu 24.04 LTS veya RHEL / Rocky Linux 9
İşlemci (CPU) 2 vCPU 4 vCPU veya üzeri (Xeon / EPYC / Ryzen)
Bellek (RAM) 2 GB RAM 4 GB – 8 GB RAM
Depolama 15 GB SSD 50 GB+ NVMe SSD (Ses kayıtları için)
Ağ (Network) Statik Yerel IP Statik Genel IPv4 ve Yönlendirilmiş FQDN Alan Adı

2. Anahtar Teslim Otomatik Kurulum (Turnkey Install)

Kurulum komutunu doğrudan sunucunuzun terminalinde root yetkisiyle çalıştırın:

Terminal Kurulum Adımı 
# 1. Depoyu klonlayın
git clone https://github.com/mahirgul/AiPBX.git /opt/aipbx
cd /opt/aipbx

# 2. Kurulum betiğini root olarak başlatın
sudo bash install.sh

Kurulum Betiğinin Otomatik Yaptığı İşlemler:

  1. Paket Kurulumları: Asterisk 22, Apache 2.4, Nginx L4 Stream, MariaDB 11, PHP 8 ve tüm uzantıları (curl, pdo_mysql, gd, mbstring, xml, zip), Go derleyicisi, Coturn ve Fail2ban kurulur.
  2. Dinamik Kriptografik Parolalar: Kodda hiçbir sabit parola bırakılmaz; veritabanı kullanıcıları (aipbx_portal, aipbx_migrator), Asterisk AMI ve coturn için 32 karakterlik rastgele güçlü şifreler üretilir.
  3. Otomatik SSL Sertifikası: Sunucu alan adınız (FQDN) girildiğinde Let's Encrypt üzerinden Certbot ile gerçek SSL sertifikası alınır. Henüz alan adı yoksa otomatik SAN destekli yerel SSL sertifikası üretilir.
  4. Veritabanı Şeması & Tohum Verisi: Phinx migration ve seed tabloları yüklenerek varsayılan yönetici hesabı oluşturulur.
  5. Parola Kasası: Üretilen tüm şifreler yalnızca root kullanıcısının okuyabileceği /root/aipbx-credentials.txt (chmod 600) dosyasına kaydedilir.

3. Ağ ve Güvenlik Duvarı Port Tablosu

AiPBX'in dış dünya ile sorunsuz haberleşebilmesi için modem veya kurumsal güvenlik duvarında aşağıdaki portların açılması gerekir:

Port Numarası Protokol Servis / Kullanım Amacı Dışarıya Açılmalı mı?
443 TCP Nginx L4 ALPN Stream (Web Paneli, WebRTC WSS, Coturn TURNS, Mobil API) EVET (Zorunlu)
80 TCP HTTP -> HTTPS Yönlendirme ve Let's Encrypt ACME HTTP-01 Doğrulama EVET
10000 - 20000 UDP Asterisk RTP Medya Akışı (Görüşmelerde ses paketlerinin iletimi) EVET (Zorunlu)
5060 UDP / TCP Donanımsal SIP Masa Telefonları & SIP Trunk Operatör Bağlantıları İsteğe Bağlı (Yalnızca masa telefonu ve trunk varsa)
5061 TCP SIP TLS (Şifreli donanım masaüstü telefon bağlantısı) İsteğe Bağlı
5038 TCP Asterisk Manager Interface (AMI - PHP Portal İletişimi) HAYIR (127.0.0.1 İç Ağ)

4. İlk Kurulum Sonrası Adımlar

Kurulum tamamlandıktan sonra santralinizi devreye almak için:

  1. Panele Giriş: Tarayıcınızda https://sunucu-ip-adresi veya alan adınızı açın. /root/aipbx-credentials.txt dosyasındaki admin bilgileriyle giriş yapın.
  2. İlk Dahiliyi Tanımlayın: Dahili Yönetimi sayfasından 1000 numaralı dahiliyi açın. Şifresini belirleyin.
  3. SIP Trunk Bağlantısı: Operatörünüzün (Türk Telekom, Netgsm vb.) verdiği SIP kullanıcı adı, şifre ve sunucu IP bilgilerini Trunk Yönetimi sayfasından kaydedin.
  4. Test Çağrısı Gerçekleştirin: Mobil AiPBX uygulamasını telefonunuza indirin, sunucu adresinizi ve dahilinizi girin; dahili veya harici bir test araması yapın.
