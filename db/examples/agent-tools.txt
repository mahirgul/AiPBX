# Format: <kind> | <values separated by |>. Lines starting with # are ignored.
# After editing this file, Apply the changes.

# Variables in sentences are written in curly brackets:
#   {caller_name}    the caller's name from the phonebook (left out when unknown)
#   {caller_number}  the caller's number
#   {did}            the number that was called

# call_transfer | target ID | destination type | PBX ID | when to transfer
# Destination type: extension (its number), queue (its name) or ring_group (its ID).
call_transfer | sales | ring_group | 1 | Callers who want to place an order, ask about prices or get a quote
call_transfer | support | queue | support | Callers with a question about an existing order, a delivery or a technical problem
call_transfer | operator | extension | 1000 | Callers who ask for a person, or when no other target fits

# Lookups (remove the leading # to use them; replace the address, the connection ID and the SQL).
# In SQL a variable the assistant asks for is written :var_<name>; the caller's answer is sent
# as a bound parameter, never pasted into the query.
# get_db_value | order_status | Status of an order by its order number | 1 | public | SELECT status FROM orders WHERE order_no = :var_order_no LIMIT 1
#
# An HTTP lookup is called with the caller's number and the values the assistant collected.
